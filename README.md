# Himam — Software Engineering Studio Website

Monorepo for the marketing website of **Himam**, a 3-person software engineering studio
building apps, websites, systems, and AI chatbots.

This is the **project skeleton** (Phase 1): a running React frontend, a running Strapi CMS,
and a connected PostgreSQL database. No page content yet — the content model contract for
later phases lives in [`docs/content-model.md`](docs/content-model.md).

## Stack

| Layer      | Technology                          | Port  |
| ---------- | ----------------------------------- | ----- |
| Frontend   | React 19 + Vite 8 + TypeScript      | 5173  |
| CMS        | Strapi 5 (TypeScript, latest LTS)   | 1337  |
| Database   | PostgreSQL 17 (Docker for dev)      | 5432  |

## Repository layout

```
.
├── frontend/     # React + Vite + TypeScript app (renders the site, consumes the CMS API)
├── cms/          # Strapi 5 headless CMS (owns ALL page content: pages, posts, services, …)
├── design-system/ # MASTER.md — single source of truth for the UI (colors, tokens, components)
├── docs/         # Architecture decisions, content model contract, team conventions
├── docker-compose.yml  # Local PostgreSQL (Strapi container optional, see file)
└── package.json        # Root convenience scripts only — no shared dependencies
```

The three apps are deliberately **independent npm projects** (each with its own
`package.json` and lockfile), not npm workspaces. This keeps Strapi's dependency tree
isolated, lets all three engineers work in parallel without lockfile conflicts, and avoids
common monorepo hoisting issues with Strapi. See [`docs/architecture.md`](docs/architecture.md).

## Prerequisites

- **Node.js 22** (Active LTS — required by Strapi 5)
- **npm** (any recent version)
- **Docker Desktop** (for the local PostgreSQL database)

## Quick start

```bash
# 1. Install dependencies (first time only)
npm --prefix frontend install
npm --prefix cms install

# 2. Start PostgreSQL
npm run db:up            # docker compose up -d db

# 3. Start the CMS (first boot: create the admin account in the browser)
npm run dev:cms          # http://localhost:1337/admin

# 4. Start the frontend, in a second terminal
npm run dev:frontend     # http://localhost:5173
```

### Environment variables

Copy the example files and fill in values (dev defaults already match the Docker
database, so you can usually get away with the examples as-is):

```bash
cp frontend/.env.example frontend/.env
cp cms/.env.example cms/.env      # or use the cms/.env generated by the installer
```

Every required variable is documented in each `.env.example`. `.env` files are
gitignored; only `.env.example` is committed. See [`docs/architecture.md`](docs/architecture.md#environment-separation).

## Useful commands

| Command                    | What it does                          |
| -------------------------- | ------------------------------------- |
| `npm run dev:frontend`     | Vite dev server on :5173              |
| `npm run dev:cms`          | Strapi dev server (watch mode) on :1337 |
| `npm run db:up`            | Start PostgreSQL container            |
| `npm run db:down`          | Stop PostgreSQL container             |
| `npm run build:frontend`   | Production build of the frontend      |
| `npm run build:cms`        | Production build of the Strapi admin  |
